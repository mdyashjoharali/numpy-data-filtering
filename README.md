# 🚀 NumPy Data Filtering

## Project Overview
This project demonstrates NumPy Boolean Indexing and Data Filtering using different threshold conditions. The program filters numerical values that are greater than, less than, or equal to a specified threshold.

## Technologies Used
- Python
- NumPy

## Features
- Boolean Indexing
- Data Filtering
- Threshold-based Selection
- Clean and Simple Implementation
